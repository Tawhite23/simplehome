# かんたんホーム（お母さん用ホームアプリ）

らくらくスマートフォン Lite（MR01）のシンプルホームの「ページの分け方」をベースにした、自作ホームアプリです。

## できること

画面下のボタン（またはスワイプ）でページを切り替えます。

| ページ | 中身 |
|---|---|
| でんわ | 連絡先の大きいボタン。押すと「〇〇さんに電話をかけますか？」→ 電話 |
| ホーム | 時計・日付 ＋ マス目。**アプリ・Webサイト・連絡先を混ぜて置ける**（お気に入り／アプリの区別なし） |
| べんり | ウィジェット（時計・天気・カレンダーなど）を縦に並べる |
| アプリ | 全アプリの一覧（あいうえお順）。長押しでホームに置ける。右上の「⚙ せってい」もここ |

- **並べ替えは入れ替え方式**：長押し →「うごかす（入れかえ）」→ 動かしたい先のマスを押す。
  先にあったアイコンが元の場所に入る。空きマスならそこへ移るだけ。**自動で詰めたり整列したりしない**。
  外したアイコンの場所も空きのまま残る。別の「ホーム」ページのマスとも入れ替えられる。
- **Webサイト**：Chromeで「︙」→「ホーム画面に追加」すると、「ホーム」の空きマスに自動で入る（このアプリが既定のホームのとき）。
- **新しく入れたアプリ**：自動で最後の「ホーム」ページの空きマスに入る（せっていでOFFにできる）。
- **せってい**：文字の大きさ（ふつう／大きい／特大）、横に並べる数（2〜4）、ホームのページ追加・削除、元のホームにもどす。
- 戻るボタン／ホームボタンで、いつでも「ホーム」ページに戻る。

## ビルド

1. Android Studio（Ladybug 以降）で「Open」→ この `KantanHome` フォルダを選ぶ
2. Gradle Sync が終わるのを待つ（初回は数分）
3. メニュー Build → Build App Bundle(s) / APK(s) → Build APK(s)
4. `app/build/outputs/apk/debug/app-debug.apk` ができる

> このプロジェクトは Android SDK のない環境で書いたので、**まだ一度もコンパイルしていません**。
> Sync やビルドでエラーが出たら、エラーメッセージをそのまま貼ってください。直します。
> Android Studio が AGP / Kotlin のアップデートを勧めてきたら、受け入れて大丈夫です。

## スマホに入れる

### 1. USBデバッグをONにする（MR01）
1. 設定 → 端末情報（「その他」の中にある場合あり）→「ビルド番号」を7回タップ
2. 開発者向けオプション →「USBデバッグ」をON
3. PCとUSBでつなぎ、スマホに出る「USBデバッグを許可しますか？」で許可

Windows で認識しない場合は、FCNT が公開している「ADB用USBドライバ」を入れる。

### 2. インストールして既定のホームにする
```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell cmd package set-home-activity jp.kantanhome.launcher/.MainActivity
```
2行目の代わりに、スマホで ホームボタン →「かんたんホーム」→「常時」を選んでもOK。
（設定 → アプリ → デフォルトのアプリ → ホームアプリ からも変えられる）

初回、連絡先を追加したときに「電話の発信を許可」が出るので許可する。
許可しない場合は、ボタンを押すとダイヤル画面が開くだけになる。

### 3. 元に戻すとき
「アプリ」ページ →「⚙ せってい」→「元のホームにもどす」→ らくらくホームを選ぶ。
アンインストールは `adb uninstall jp.kantanhome.launcher`。

## おまけ：いらないプリインアプリを消す

```sh
# 名前の一部で探す（例：stamp）
adb shell pm list packages | grep -i stamp

# この端末のユーザーからだけ消す（本体からは消えないので、初期化すれば戻る）
adb shell pm uninstall --user 0 <パッケージ名>

# 間違えて消したときに戻す
adb shell cmd package install-existing <パッケージ名>
```
電話・SMS・設定・Google Play 開発者サービスなど、システムに関わるものは消さないこと。
パッケージ名が何のアプリか分からなければ、消す前に調べる。

## 注意

- らくらくホーム独自のボタン（ワンタッチダイヤル、よく使うブックマーク等）はこのホームには出ません。「でんわ」ページと Web ショートカットで代わりにしています。
- PWA 対応サイトは Chrome で「インストール」になり、アプリとして入ります。その場合も自動でホームに置かれます。
- ウィジェットの追加時に「ウィジェットの作成とアクセスを許可しますか？」が出たら「常に許可」で次回から出なくなります。

## 構成

```
app/src/main/java/jp/kantanhome/launcher/
  MainActivity.kt          ホーム画面本体（起動・電話・連絡先・ウィジェット追加）
  PinShortcutActivity.kt   Chrome の「ホーム画面に追加」を受け取る
  data/Models.kt           ページとアイテムの型、JSON 変換
  data/HomeStore.kt        配置の保存・入れ替え・追加・削除、アプリの増減の監視
  data/AppCatalog.kt       アプリ一覧
  data/IconCache.kt        アイコン読み込み
  ui/HomeScreen.kt         ページ切り替え・移動モード・ダイアログの出し分け
  ui/GridPage.kt           マス目ページ
  ui/ListPages.kt          でんわ／べんり／アプリ ページ
  ui/Dialogs.kt            長押しメニュー・追加・設定など
  ui/Components.kt         ボタン・タイル・時計などの部品
  ui/Theme.kt              色と文字サイズ
```
