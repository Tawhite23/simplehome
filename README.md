# かんたんホーム（お母さん用ホームアプリ）

らくらくスマートフォン Lite（MR01）のシンプルホームの「ページの分け方」をベースにした、自作ホームアプリです。

## できること

iPhone のホーム画面に寄せたデザイン（グラデーションの壁紙、角丸アイコン＋白い名前、すりガラス風のドック）。
左右にめくるとページが変わる。下の点を押しても移れる。

| ページ | 中身 |
|---|---|
| ウィジェット（いちばん左） | 時計・天気・カレンダーなどを縦に並べる（iPhone の「今日の表示」） |
| ホーム | 時計ウィジェット＋マス目。**アプリ・Webサイト（Chromeのお気に入り）・連絡先を混ぜて置ける** |
| アプリ（いちばん右） | 全アプリの一覧。長押しでホームやドックに置ける。「せってい」もここ |

- **よく連絡する人（ドック）**：ホーム画面の下に4枠。らくらくホームの下段の連絡先と同じ役目。押すと「〇〇さんに電話をかけますか？」。空き枠の「＋」から追加。
- **並べ替えは入れ替え方式**：長押し →「うごかす（入れかえ）」→ 動かしたい先を押す。
  移動先にあったアイコンが移動元に入る。**自動で詰めたり整列したりしない**。
  ホームの別ページ、ドックの枠とも入れ替えられる。Webショートカットもアプリと同じ扱い。
- **Webサイト**：Chromeで「︙」→「ホーム画面に追加」すると、ホームの空きマスに自動で入る（このアプリが既定のホームのとき）。
- **新しく入れたアプリ**：自動で最後のホームページの空きマスに入る（せっていでOFFにできる）。
- **アイコン・名前をかえる**：長押し →「アイコン・名前をかえる」。写真から（連絡先なら顔写真）、色と文字でつくる、名前の変更、元にもどす。
- **アイコンの形をそろえる**：丸いアイコンしかない古いアプリも、中身を広げて角をふちの色で塗り、角丸いっぱいに表示する。せっていで全体をON/OFF、アプリごとに「元の形のまま」にもできる。
- **せってい**：かべがみ（4種類）、文字の大きさ、横に並べる数（2〜4）、アイコンの形、ホームのページ追加・削除、元のホームにもどす。
- 戻るボタン／ホームボタンで、いつでもホームに戻る。

> らくらくホームに登録済みの連絡先（下段・ワンタッチダイヤル）は、FCNTのアプリの中に保存されているので自動では移せない。ドックの「＋」から電話帳で選び直す。

## ビルド（GitHub Actions）

GitHub に push すると Actions が APK を作る。Actions タブ → 最新の「Build APK」→ 下の Artifacts から `kantanhome-debug-apk` をダウンロード。

## ビルド（Android Studio）

1. Android Studio（Ladybug 以降）で「Open」→ この `KantanHome` フォルダを選ぶ
2. Gradle Sync が終わるのを待つ（初回は数分）
3. メニュー Build → Build App Bundle(s) / APK(s) → Build APK(s)
4. `app/build/outputs/apk/debug/app-debug.apk` ができる

> このプロジェクトは Android SDK のない環境で書いたので、最初の確認は GitHub Actions のビルドで行う。
> Sync やビルドでエラーが出たら、エラーメッセージをそのまま貼ってください。直します。
> Android Studio が AGP / Kotlin のアップデートを勧めてきたら、受け入れて大丈夫です。

## スマホに入れる

### 1. USBデバッグをONにする（MR01）
1. 設定 → 端末情報（「その他」の中にある場合あり）→「ビルド番号」を7回タップ
2. 開発者向けオプション →「USBデバッグ」をON
3. PCとUSBでつなぎ、スマホに出る「USBデバッグを許可しますか？」で許可

Windows で認識しない場合は、FCNT が公開している「ADB用USBドライバ」を入れる。

### 2. インストールして既定のホームにする
```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell cmd package set-home-activity jp.kantanhome.launcher/.MainActivity
```
2行目の代わりに、スマホで ホームボタン →「かんたんホーム」→「常時」を選んでもOK。
（設定 → アプリ → デフォルトのアプリ → ホームアプリ からも変えられる）

初回、連絡先を追加したときに「電話の発信を許可」が出るので許可する。
許可しない場合は、ボタンを押すとダイヤル画面が開くだけになる。

### 3. 元に戻すとき
どれか1つでOK。
- かんたんホームの右端「アプリ」→「せってい」→「元のホームにもどす」→ 元のホームを選ぶ
- スマホの 設定 → アプリ → デフォルトのアプリ → ホームアプリ → 元のホームを選ぶ
- adb：元のホームの名前を調べてから切り替える
  ```
  adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.HOME
  adb shell cmd package set-home-activity <上で出た元のホームのパッケージ名/クラス名>
  ```
- アンインストール（`adb uninstall jp.kantanhome.launcher`）すると、自動で元のホームに戻る

## おまけ：いらないプリインアプリを消す

```sh
# 名前の一部で探す（例：stamp）
adb shell pm list packages | grep -i stamp

# この端末のユーザーからだけ消す（本体からは消えないので、初期化すれば戻る）
adb shell pm uninstall --user 0 <パッケージ名>

# 間違えて消したときに戻す
adb shell cmd package install-existing <パッケージ名>
```
電話・SMS・設定・Google Play 開発者サービスなど、システムに関わるものは消さないこと。
パッケージ名が何のアプリか分からなければ、消す前に調べる。

## 注意

- らくらくホーム独自のボタン（ワンタッチダイヤル、よく使うブックマーク等）はこのホームには出ません。ドックと Web ショートカットで代わりにしています。
- PWA 対応サイトは Chrome で「インストール」になり、アプリとして入ります。その場合も自動でホームに置かれます。
- ウィジェットの追加時に「ウィジェットの作成とアクセスを許可しますか？」が出たら「常に許可」で次回から出なくなります。

## 構成

```
app/src/main/java/jp/kantanhome/launcher/
  MainActivity.kt          ホーム画面本体（起動・電話・連絡先・ウィジェット追加）
  PinShortcutActivity.kt   Chrome の「ホーム画面に追加」を受け取る
  data/Models.kt           ページとアイテムの型、JSON 変換
  data/HomeStore.kt        配置の保存・入れ替え・追加・削除、アプリの増減の監視
  data/AppCatalog.kt       アプリ一覧
  data/IconCache.kt        アイコン読み込み
  ui/HomeScreen.kt         ページ切り替え・移動モード・ダイアログの出し分け
  ui/GridPage.kt           マス目ページとドック
  ui/ListPages.kt          ウィジェット／アプリ ページ
  ui/Dialogs.kt            長押しメニュー・追加・設定など
  ui/Components.kt         ボタン・タイル・時計などの部品
  ui/Theme.kt              色と文字サイズ
```
